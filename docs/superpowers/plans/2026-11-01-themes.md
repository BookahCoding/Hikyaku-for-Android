# Themes instead of accents, with matching icons — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the accent picker with a theme picker (Ukiyo-e kept, five new themes, three of them with a secondary colour) and give each theme a launcher icon that follows it.

**Architecture:** Themes are `AppTheme` values (renamed from `AccentPalette`) that carry their own `Neutrals` (the way Ukiyo-e already does); five are added in a new `Themes.kt`, the six plain accents are retired from `AppTheme.all`, `AppSettings.theme` keeps its storage but unknown names read as Ukiyo-e. The Settings accent swatches become theme cards. Launcher icons reuse the existing alias-per-icon system; picking a theme queues its icon, applied without a restart when the app is left.

**Tech Stack:** Kotlin Multiplatform, Compose Multiplatform, Android adaptive-icon vector XML, kotlin.test.

**Spec:** `docs/superpowers/specs/2026-11-01-themes-design.md`

**Plan decisions that differ from the spec text:**
1. The spec's rename is done, and a little further: `AccentPalette` → `AppTheme`, `AccentColors` → `ThemeVariant` (it holds a variant's accent *and* neutrals now), `LocalAccentPalette` → `LocalAppTheme`, `AppSettings.accent` → `AppSettings.theme` (the stored key stays `"accent"` so saved settings still load), `DEFAULT_ACCENT` → `DEFAULT_THEME`. Task 0 does it mechanically before anything else.
2. The spec's secondary colours are implemented, not dropped: a theme variant may carry a secondary colour (`secondary`, `onSecondary`, `secondaryText`, `secondarySoft` tokens; absent ⇒ identical to the accent so plain themes look as before). It is used for links in chat text, unread dots, and the assistant's edge light (Tasks 1 and 5).
3. The colour values below were checked against the contrast rules with a script. Two spec secondaries had to be lightened for dark grounds because they fail 4.5:1 there: ochre `#B8862B` → `#D4A03E`, violet `#8B5CFF` → `#A080FF`. Light variants use darker versions of each secondary (ochre `#7A5200`, cyan `#00677B`, violet `#5A2DD0`).
4. The default launcher alias (`.MainActivity`) already draws the Ukiyo-e icon (washi mark on vermilion). So the enum entry `Blue` is renamed `Ukiyoe` and keeps that alias; no separate hidden entry is needed.
5. The six theme icons replace the "Colors" icon group; the "Patterns" group stays.

package dev.hermeskotlin.designsystem

import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.compositeOver
import androidx.compose.ui.graphics.luminance
import kotlin.math.abs
import kotlin.math.cbrt
import kotlin.math.max
import kotlin.math.min
import kotlin.math.sqrt
import kotlin.test.Test
import kotlin.test.assertEquals
import kotlin.test.assertNotNull
import kotlin.test.assertTrue

/** Every theme with a look of its own can be read, in light, dark and pure black. */
class ThemesTest {
    private val themes = listOf(Themes.GreatWave, Themes.RedFuji, Themes.ThirtySixViews)

    private fun contrast(a: Color, b: Color): Float {
        val la = a.luminance(); val lb = b.luminance()
        return (max(la, lb) + 0.05f) / (min(la, lb) + 0.05f)
    }

    private fun schemes(p: AppTheme) = mapOf(
        "light" to lightColors(p.light), "dark" to darkColors(p.dark), "black" to pureBlackColors(p.black),
    )

    private val grounds = listOf(background, surface, surface2, surface3, surfaceElevated)

    private fun lab(c: Color): Triple<Double, Double, Double> {
        fun lin(v: Float) = v.toDouble().let { if (it <= 0.04045) it / 12.92 else Math.pow((it + 0.055) / 1.055, 2.4) }
        val r = lin(c.red); val g = lin(c.green); val b = lin(c.blue)
        val x = (0.4124 * r + 0.3576 * g + 0.1805 * b) / 0.95047
        val y = 0.2126 * r + 0.7152 * g + 0.0722 * b
        val z = (0.0193 * r + 0.1192 * g + 0.9505 * b) / 1.08883
        fun f(t: Double) = if (t > 0.008856) cbrt(t) else 7.787 * t + 16.0 / 116
        return Triple(116 * f(y) - 16, 500 * (f(x) - f(y)), 200 * (f(y) - f(z)))
    }
    private fun difference(a: Color, b: Color): Double {
        val (l1, a1, b1) = lab(a); val (l2, a2, b2) = lab(b)
        return sqrt((l1 - l2) * (l1 - l2) + (a1 - a2) * (a1 - a2) + (b1 - b2) * (b1 - b2))
    }
    private fun hue(c: Color) = Math.toDegrees(Math.atan2(lab(c).third, lab(c).second)).let { if (it < 0) it + 360 else it }

    @Test
    fun everyThemeBringsItsOwnNeutralsAndIsListed() {
        for (p in themes) {
            assertNotNull(p.light.neutrals, p.name); assertNotNull(p.dark.neutrals, p.name); assertNotNull(p.black.neutrals, p.name)
            assertTrue(p in AppTheme.all, p.name)
            assertEquals(p, AppTheme.named(p.name))
        }
    }

    @Test
    fun pureBlackIsBlackAndTheGroundsStayOrdered() {
        for (p in themes) assertEquals(Color.Black, schemes(p).getValue("black").getValue(background), p.name)
    }

    @Test
    fun everyTextStepReadsOnEveryGround() {
        for (p in themes) for ((scheme, c) in schemes(p)) {
            val tinted = c.getValue(accentSoft).compositeOver(c.getValue(surface))
            for (g in grounds.map { c.getValue(it) } + tinted + c.getValue(well)) {
                assertTrue(contrast(c.getValue(text), g) >= 7f, "${p.name} $scheme text on $g")
                assertTrue(contrast(c.getValue(textSecondary), g) >= 7f, "${p.name} $scheme secondary on $g")
                assertTrue(contrast(c.getValue(textTertiary), g) >= 4.5f, "${p.name} $scheme tertiary on $g")
            }
        }
    }

    @Test
    fun accentTextAndSignalsReadOnTheGrounds() {
        for (p in themes) for ((scheme, c) in schemes(p)) {
            val tinted = c.getValue(accentSoft).compositeOver(c.getValue(surface))
            for (g in grounds.map { c.getValue(it) } + tinted) {
                assertTrue(contrast(c.getValue(accentText), g) >= 4.5f, "${p.name} $scheme accent text on $g")
            }
            for (s in listOf(danger, success, warning)) for (g in grounds.map { c.getValue(it) }) {
                assertTrue(contrast(c.getValue(s), g) >= 4.5f, "${p.name} $scheme signal on $g")

                assertTrue(contrast(colors.onAccent, colors.accent) >= 4.5f, "${p.name} $scheme on-accent")

                assertTrue(contrast(c.getValue(onInverse), c.getValue(inverse)) >= 7f, "${p.name} $scheme inverse")

            }
        }
    }

    @Test
    fun aSecondaryColourReadsWhereAThemeHasOne() {
        for (p in themes) for ((scheme, colors) in listOf("light" to p.light, "dark" to p.dark, "black" to p.black)) {
            if (!colors.hasSecondary) continue
            val c = when (scheme) { "light" -> lightColors(colors); "dark" -> darkColors(colors); else -> pureBlackColors(colors) }
            val tinted = c.getValue(secondarySoft).compositeOver(c.getValue(surface))
            for (g in grounds.map { c.getValue(it) } + tinted) {
                assertTrue(contrast(c.getValue(secondaryText), g) >= 4.5f, "${p.name} $scheme secondary text on $g")
            }
            assertTrue(contrast(colors.onSecondary, colors.secondary) >= 4.5f, "${p.name} $scheme on-secondary")
            assertTrue(difference(colors.secondary, colors.accent) >= 20.0, "${p.name} $scheme secondary looks like the accent")

            assertTrue(gap >= 15.0, "${p.name} $scheme danger vs accent hue $gap")
        }
    }

```kotlin
package dev.hermeskotlin.designsystem

import androidx.compose.ui.graphics.Color
import androidx.compose.ui.graphics.lerp

/**
 * The themes with a look of their own besides Ukiyo-e (which lives in [AppTheme]). Each brings its own neutrals for
 * light, dark and pure black; the colours were checked against ThemesTest's contrast rules. A theme's accent is its fill
 * and its text alike, as the plain presets do.
 */
internal object Themes {
    private val OnDark = Color(0xFF0A0A0C)

    private fun k(rgb: Long) = Color(0xFF000000L or rgb)

    private fun light(
        bg: Long, surface: Long, surface2: Long, surface3: Long, well: Long,
        text: Long, text2: Long, text4: Long, danger: Long, success: Long, warning: Long,
    ): Neutrals {
        val t = k(text); val b = k(bg); val s = k(surface)
        return Neutrals(
            bg = b, surface = s, surface2 = k(surface2), surface3 = k(surface3), well = k(well), thumb = s, elevated = s,
            line = t.copy(alpha = 0.12f), lineStrong = t.copy(alpha = 0.20f),
            text = t, text2 = k(text2), text4 = k(text4), text5 = lerp(k(text4), b, 0.35f),
            inverse = t, onInverse = s, danger = k(danger), success = k(success), warning = k(warning),
        )
    }

    private fun dark(
        bg: Long, surface: Long, surface2: Long, surface3: Long, well: Long, elevated: Long,
        text: Long, text2: Long, text4: Long, danger: Long, success: Long, warning: Long,
    ): Neutrals {
        val t = k(text); val b = k(bg)
        return Neutrals(
            bg = b, surface = k(surface), surface2 = k(surface2), surface3 = k(surface3), well = k(well),
            thumb = lerp(k(surface3), t, 0.10f), elevated = k(elevated),
            line = t.copy(alpha = 0.08f), lineStrong = t.copy(alpha = 0.14f),
            text = t, text2 = k(text2), text4 = k(text4), text5 = lerp(k(text4), b, 0.35f),
            inverse = t, onInverse = b, danger = k(danger), success = k(success), warning = k(warning),
        )
    }

    /** Pure black: the grounds pulled 45% toward black, the text and signals as in dark. */
    private fun black(d: Neutrals): Neutrals {
        fun toBlack(c: Color) = lerp(c, Color.Black, 0.45f)
        return Neutrals(
            bg = Color.Black, surface = toBlack(d.surface), surface2 = toBlack(d.surface2), surface3 = toBlack(d.surface3),
            well = toBlack(d.well), thumb = d.thumb, elevated = toBlack(d.elevated),
            line = d.line, lineStrong = d.lineStrong, text = d.text, text2 = d.text2, text4 = d.text4, text5 = d.text5,
            inverse = d.inverse, onInverse = d.onInverse, danger = d.danger, success = d.success, warning = d.warning,
        )
    }

    /** [lightSecondary] / [darkSecondary] give the theme a second colour; without them it is the accent itself. */
    private fun theme(
        name: String, light: Neutrals, dark: Neutrals, lightAccent: Long, darkAccent: Long,
        lightSecondary: Long? = null, darkSecondary: Long? = null,
    ): AppTheme {
        fun colors(fill: Color, on: Color, n: Neutrals, soft: Float, secondary: Long?): ThemeVariant {
            val s = secondary?.let(::k)
            return ThemeVariant(
                fill, on, text = fill, soft = fill.copy(alpha = soft), neutrals = n,
                secondary = s ?: fill, onSecondary = on, secondaryText = s ?: fill, secondarySoft = (s ?: fill).copy(alpha = soft),
            )
        }
        val l = k(lightAccent); val d = k(darkAccent)
        return AppTheme(
            name,
            light = colors(l, Color.White, light, 0.10f, lightSecondary),
            dark = colors(d, OnDark, dark, 0.14f, darkSecondary),
            black = colors(d, OnDark, black(dark), 0.14f, darkSecondary),
        )
    }

    /** "Great Wave": foam cream and Prussian blue, from the Kanagawa print. */
    val GreatWave: AppTheme = theme(
        "Great Wave",
        light(0xF3EBD8, 0xFAF4E4, 0xEEE5CE, 0xE4D9BD, 0xEFE7D2, text = 0x1B2A41, text2 = 0x2A3B55, text4 = 0x4F5F78, danger = 0xA32E2A, success = 0x2A6347, warning = 0x7A4F00),
        dark(0x0B1A33, 0x12213F, 0x182B4D, 0x20375E, 0x0D1B36, 0x14264A, text = 0xEAE3CF, text2 = 0xD2CCBA, text4 = 0xA5ABBA, danger = 0xF08A7C, success = 0x7FCBA0, warning = 0xE3B458),
        lightAccent = 0x1F4E8C, darkAccent = 0x7FB0E8,
    )

    /** "Red Fuji": dawn pink and warm charcoal, with the mountain's red, from "Fine Wind, Clear Morning". */
    val RedFuji: AppTheme = theme(
        "Red Fuji",
        light(0xF7E9E1, 0xFDF3EC, 0xF1E0D6, 0xE8D3C6, 0xF3E4DA, text = 0x2A1F1D, text2 = 0x3D2E2B, text4 = 0x6B5550, danger = 0x7A1F4A, success = 0x2F5E3C, warning = 0x7A4F00),
        dark(0x1C1614, 0x251D1A, 0x2E2420, 0x3A2D28, 0x181210, 0x271F1C, text = 0xF2E4DA, text2 = 0xDCCDC2, text4 = 0xB5A398, danger = 0xF2799B, success = 0x8CC79A, warning = 0xE6B85C),
        lightAccent = 0xA33524, darkAccent = 0xE8826A,
    )

    /** "Thirty-six Views": celadon and pine night, from the green of Hokusai's landscapes. */

package dev.hermeskotlin.ui.settings

// imports: the ones AccentPicker used, plus androidx.compose.foundation.layout.*, background, border, clickable,
// androidx.compose.ui.semantics.*, Text, Theme tokens as in SettingsScreen.kt

internal class ThemeSwatch(val background: Color, val surface: Color, val accent: Color, val text: Color)

/** The colours of [palette]'s preview card in the scheme currently in force. */
internal fun themeSwatch(palette: AppTheme, dark: Boolean): ThemeSwatch {
    val colors = if (dark) palette.dark else palette.light
    val n = colors.neutrals ?: error("${palette.name} has no neutrals")
    return ThemeSwatch(background = n.bg, surface = n.surface2, accent = colors.accent, text = n.text)
}

internal fun themeLabel(palette: AppTheme, selected: Boolean): String =
    if (selected) "${palette.name}, selected" else palette.name

/**
 * One card per theme: a small page in the theme's own ground with a surface bar, an accent chip and a text line, the name
 * under it, a ring and a check mark on the picked one (so the pick shows without relying on colour). Cards wrap on a
 * narrow phone, each a 48dp-minimum touch target and a radio for screen readers.
 */
@OptIn(ExperimentalLayoutApi::class)
@Composable
internal fun ThemePicker(selected: AppTheme, onSelect: (AppTheme) -> Unit) {
    val dark = Theme[colors][background].luminance() < 0.5f
    FlowRow(Modifier.selectableGroup(), horizontalArrangement = Arrangement.spacedBy(10.dp), verticalArrangement = Arrangement.spacedBy(10.dp)) {
        AppTheme.all.forEach { palette ->
            val isSelected = palette == selected
            val swatch = themeSwatch(palette, dark)
            Column(
                Modifier
                    .width(104.dp)
                    .selectable(selected = isSelected, role = Role.RadioButton, onClick = { onSelect(palette) })
                    .semantics { contentDescription = themeLabel(palette, isSelected) },
                verticalArrangement = Arrangement.spacedBy(6.dp),
            ) {
                Box(
                    Modifier
                        .fillMaxWidth().height(64.dp)
                        .clip(RoundedCornerShape(12.dp))
                        .background(swatch.background)
                        .border(if (isSelected) 2.dp else 1.dp, if (isSelected) swatch.accent else swatch.text.copy(alpha = 0.18f), RoundedCornerShape(12.dp))
                        .padding(8.dp),
                ) {
                    Column(verticalArrangement = Arrangement.spacedBy(5.dp)) {
                        Box(Modifier.fillMaxWidth().height(14.dp).clip(RoundedCornerShape(4.dp)).background(swatch.surface))
                        Box(Modifier.width(34.dp).height(10.dp).clip(RoundedCornerShape(5.dp)).background(swatch.accent))
                        Box(Modifier.fillMaxWidth(0.7f).height(4.dp).clip(RoundedCornerShape(2.dp)).background(swatch.text.copy(alpha = 0.7f)))
                    }
                    if (isSelected) Text("✓", color = swatch.accent, modifier = Modifier.align(Alignment.TopEnd))
                }
                Text(palette.name, style = Theme[typography][bodySmall], color = Theme[colors][textColor], maxLines = 1, overflow = TextOverflow.Ellipsis)
            }
        }
    }
}

/** The icon a theme pick asked for, held until the app is left; the last pick wins. */
class PendingIcon {
    private var icon: AppIcon? = null
    fun set(icon: AppIcon?) { this.icon = icon }
    /** The icon to switch to, or null when nothing is pending or it is the one already shown; forgets it either way. */
    fun take(current: AppIcon): AppIcon? = icon?.takeIf { it != current }.also { icon = null }
}
```

Android (`AppIcons.android.kt`): add a process-wide holder and a quiet apply:

```kotlin
internal object AppIconPending { val pending = PendingIcon() }

override fun applyWhenLeaving(icon: AppIcon) = AppIconPending.pending.set(icon)

/** Switches to the pending icon, if any, the way [apply] does but with no restart: called when the app goes to the background. */
fun flushPendingIcon(context: Context) {
    val packages = context.packageManager
    val current = packages.getLaunchIntentForPackage(context.packageName)?.component?.className
        .let { entry -> AppIcon.entries.firstOrNull { it.aliasClass == entry } } ?: AppIcon.Ukiyoe
    val icon = AppIconPending.pending.take(current) ?: return
    val changes = listOf(icon to PackageManager.COMPONENT_ENABLED_STATE_ENABLED) +
        AppIcon.entries.filter { it != icon }.map { it to PackageManager.COMPONENT_ENABLED_STATE_DISABLED }
    changes.forEach { (it, state) -> packages.setComponentEnabledSetting(ComponentName(context.packageName, "dev.hermeskotlin.android" + it.aliasClass), state, PackageManager.DONT_KILL_APP) }
}
```
